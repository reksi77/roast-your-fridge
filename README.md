A tiny Node program that writes one original roast line about a fridge — the egg tray with twelve little thrones for eggs bought in sixes — to `/output/entry.txt`. One line, 195 characters, deadpan, with the twist landing in the last few words.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and refuses to write anything that would fail the gate: the line must be 1–200 characters, a single line, valid UTF-8, and not only whitespace.
